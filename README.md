# Backend Knowledge Base

Русскоязычная техническая база знаний и справочник для Go backend-разработчиков. Материалы можно читать в любом порядке. Исходные статьи хранятся в этом репозитории; GitBook публикует их и показывает оглавление.

Редакция для подготовки к Senior: объяснения механизмов, разобранные примеры, схемы и вопросы с ответами. Откройте [базу](docs/README.md) или [инструкцию для ежедневных устных занятий](docs/voice-study.md). Новая переработка объяснений описана в [журнале читаемости](maintenance/READABILITY_2026-10-06.md), предыдущая техническая проверка — в [журнале редакции для Senior](maintenance/SENIOR_REVIEW_2026-10-06.md).

## Публичная версия

[Читать базу в GitBook](https://leary-1.gitbook.io/leary-docs/). Публикация связана с веткой `master` через Git Sync; пути существующих статей сохранены.

## Структура

- [`docs/`](docs/) — публикуемый контент;
- [`docs/SUMMARY.md`](docs/SUMMARY.md) — навигация GitBook;
- [`maintenance/`](maintenance/) — аудит, журнал миграции и backlog;
- [`.gitbook.yaml`](.gitbook.yaml) — корень и структура GitBook.

## Локальная работа

Специальная сборка не нужна: откройте Markdown-файлы в любом редакторе. Перед pull request запустите:

```powershell
pwsh scripts/check-docs.ps1
```

Правила оформления и проверки описаны в [`CONTRIBUTING.md`](CONTRIBUTING.md).

## GitBook Git Sync

GitBook читает документацию из `docs/`. Главная страница — `docs/README.md`, тематическое оглавление — `docs/SUMMARY.md`. Изменения следует вносить в GitHub; после подключения Git Sync они публикуются из выбранной ветки.
