# Практика

Раздел связывает language, storage, messaging, reliability, observability и operations в проверяемых проектах. Начните с [Ads Service roadmap](go-backend-project.md): сначала реализуйте correctness на PostgreSQL, затем по одному добавляйте cache, events, telemetry и deployment, каждый раз фиксируя contract и failure tests.

Roadmap — reference, а не готовое приложение или обязательная структура repository. Продвинутый результат оценивается по idempotency, degradation, migrations, diagnostic evidence и graceful lifecycle, а не числу подключённых технологий.
