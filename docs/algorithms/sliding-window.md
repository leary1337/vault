# Скользящее окно

Скользящее окно рассматривает текущий непрерывный участок. Правая граница добавляет элементы, левая убирает ненужные. Вместо пересчёта всего участка поддерживается сумма, частота или другая характеристика.

## Как двигаются границы

Для строки без повторов добавьте очередной символ. Если он уже в окне, перенесите начало за его прошлое вхождение. Левая граница только растёт; повтор вне текущего окна не должен возвращать её назад. После исправления окно снова не содержит повторов, и его длину можно сравнить с лучшей.

Для фиксированного окна суммы добавляют входящее число и вычитают уходящее. Для переменной длины нужно доказать, что направление изменения свойства позволяет двигать границу без возврата.

## Когда обычное окно не подходит

Для поиска короткого участка с суммой не меньше S неотрицательные числа обеспечивают нужное направление изменения суммы. Отрицательное число ломает его: удаление может увеличить сумму. Пример ниже показывает, почему старый цикл не исправляется одной дополнительной проверкой.

Если каждая граница движется не более n раз, работа `O(n)`, даже с вложенным циклом. Частоты занимают память по числу разных значений. В строках Go уточните единицу: байты, кодовые точки Unicode (`rune`) или видимые пользователю символы из нескольких кодовых точек.

## Самая длинная строка без повторов

Для abba: a → окно a длиной1; b → ab длиной2; второй b требует убрать старый b и a, left=2, окно b; a → ba длиной2. Ответ2. Когда a повторяется, его прежняя позиция0 уже вне окна: left нельзя откатить к1. Инвариант: текущий участок не содержит повторов, left только растёт.

Для минимального отрезка суммы>=S обычное уменьшение работает на неотрицательных числах. При [3,-2,5], S=5 удаление левого3 меняет сумму с6 до3, затем удаление -2 увеличивает её до5: условие не монотонно. Нужны prefix sums и монотонная deque либо другой метод, а не тот же while.

Сумма окна длины K обновляется прибавлением нового и вычитанием уходящего элемента. Для уникальности нужны частоты или последние позиции. В Go позиция байта отличается от позиции `rune`; видимый пользователю символ тоже может содержать несколько кодовых точек. Выберите единицу по условию до реализации.

## Проверь себя

1. **Почему left не уменьшается при старом повторе?**

   <details>
   <summary>Ответ</summary>

   Вхождение вне окна не должно возвращать границу назад; поддерживаемый участок уже корректен.

   </details>

2. **Почему отрицательные числа мешают обычному окну суммы?**

   <details>
   <summary>Ответ</summary>

   Удаление элемента может увеличить сумму, а добавление уменьшить. Нужная монотонность пропадает.

   </details>
