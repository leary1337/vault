# Хеш-таблицы

Хеш-таблица находит значение по ключу. В Go это `map`. Она полезна, когда нужно помнить уже встреченные элементы, считать частоты или быстро проверить наличие подходящего значения.

## Как она помогает сумме двух элементов

Для текущего числа `value` нужен предыдущий элемент `target-value`. Сначала проверяем его в таблице, затем сохраняем текущий. Важен именно порядок: текущий индекс ещё не должен находиться среди кандидатов, иначе одно число ошибочно используется дважды.

Для частот храните количество, не только признак наличия. Для группы анаграмм нужен одинаковый ключ у одинакового набора символов: например, отсортированные символы или таблица частот. Простое совпадение длины недостаточно.

## Цена и ограничения

Поиск обычно имеет ожидаемую `O(1)` стоимость после хеширования, но это не универсальная гарантия худшего случая. Обработка n элементов требует `O(n)` времени в этих предположениях и до `O(n)` памяти. Длинный строковый ключ дополнительно нужно прочитать для хеширования.

Порядок обхода Go map не гарантирован. Используйте второй результат `value,ok`, чтобы различать отсутствующий ключ и нулевое значение. Обычная map не предназначена для несогласованных конкурентных записей. На алгоритмической задаче отдельно проверяйте переполнение арифметики ключа.

## Two Sum: проверка до вставки

```go
func twoSum(a []int, target int) (int, int, bool) {
	seen := make(map[int]int)
	for i, value := range a {
		if j, ok := seen[target-value]; ok {
			return j, i, true
		}
		seen[value] = i
	}
	return 0, 0, false
}
```

Для `[3,3]`, цели 6 первый элемент не находит дополнение и сохраняется. Второй находит индекс 0, ответ `(0,1,true)`. Для единственного `[3]` ответ false. Вставка до поиска дала бы совпадение элемента с самим собой. На каждом шаге таблица содержит только индексы меньше текущего — это инвариант решения.

Предполагается, что `target-value` не переполняет тип. При произвольных целых границах вычисление нужно защитить. Для анаграмм одинаковый набор символов должен давать одинаковый ключ: частоты или отсортированную копию. Визуально похожие символы Unicode не обязательно одинаковы по кодовым точкам; нормализацию определяет условие задачи.

## Проверь себя

1. **Почему дополнение ищут до вставки текущего элемента?**
