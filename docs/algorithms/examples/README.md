# Исполняемые примеры алгоритмов

Модуль хранит функции из [Разобранные функции Go](../go-examples.md), [динамики](../dynamic-programming.md), [перебора с возвратом](../backtracking.md), [Префиксные суммы](../prefix-sum.md), [Хеш-таблицы](../hash-tables.md) и [Сортировка](../sorting.md). Это отдельный учебный пакет.

```powershell
Set-Location D:\vault\docs\algorithms\examples
go test -v ./...
```

На другой машине замените путь путём к своей копии репозитория. Для Linux/macOS перейдите в эту же директорию и выполните go test. Go-модуль фиксирует golang.org/x/sync для errgroup. Проверки сопоставляют результат с контрактом, проверяют пустой вход, дубли, вытеснение LRU, изменение приоритета в куче, препятствия сетки и отмену при незакрытом канале задач. Проверка гонок памяти запускается отдельно через `go test -race ./...` при поддержке среды.

Тесты не проверяют все возможные входы и не заменяют доказательство инварианта. У shortestGrid требуется прямоугольная сетка, у Two Sum отсутствие арифметического переполнения. `minCoins` требует разумного значения суммы `amount` для выделения памяти. LRU не потокобезопасен и ограничивает число записей, а размер в байтах не ограничивает.
