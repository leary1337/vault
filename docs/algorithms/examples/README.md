# Исполняемые примеры алгоритмов

Модуль хранит функции из [примеров Go](../go-examples.md), [DP](../dynamic-programming.md), [backtracking](../backtracking.md), [префиксных сумм](../prefix-sum.md), [хеш-таблиц](../hash-tables.md) и [сортировки](../sorting.md). Это отдельный учебный пакет.

```powershell
Set-Location D:\vault\docs\algorithms\examples
go test -v ./...
```

На другой машине замените путь своим checkout. Для Linux/macOS перейдите в эту же директорию и выполните go test. Go-модуль фиксирует golang.org/x/sync для errgroup. Проверки сопоставляют результат с контрактом, проверяют пустой вход, дубли, вытеснение LRU, изменение приоритета в куче, препятствия сетки и отмену при незакрытом канале jobs. Race detector запускается отдельно через go test -race ./... при поддержке среды.

Тесты не проверяют все возможные входы и не заменяют доказательство инварианта. У shortestGrid требуется прямоугольная сетка, у Two Sum отсутствие арифметического переполнения. minCoins требует разумного amount для выделения памяти. LRU не потокобезопасен и ограничивает число записей, а размер в байтах не ограничивает.
