# Объединение одинаковых одновременных запросов

Если сто клиентов одновременно запросили отсутствующую в кэше карточку, необязательно сто раз читать БД. Singleflight выполняет одну загрузку, а остальные ожидающие получают её результат.

## Как это работает

Ключ описывает именно одинаковую работу: ID объявления, арендатора, параметры и права, влияющие на результат. Первый вызов запускает загрузчик, остальные присоединяются. Когда загрузка закончилась, группа ожидания исчезает. Это не кэш: следующий вызов снова выполнит работу, если результат не сохранён отдельно.

В Go пакет golang.org/x/sync/singleflight действует внутри одного процесса. Пятьдесят экземпляров сервиса всё ещё могут одновременно выполнить пятьдесят загрузок. Кроме того, отмена одного клиента не должна случайно отменить работу для остальных: общий загрузчик получает собственный ограниченный срок, а каждый клиент отдельно прекращает ожидание.

Результат разделяют все ожидающие. Если это изменяемая карта или срез, договоритесь о неизменности либо возвращайте копии, чтобы один клиент не менял данные другого.

## Разобранный пример

Метод Do ждёт общий результат и не принимает context. DoChan возвращает канал результата: клиент может ждать через select вместе с отменой своего контекста. Отмена такого ожидания автоматически не останавливает общий загрузчик, а канал результата не закрывается.

Загрузчик получает собственный ограниченный срок, чтобы отмена первого клиента не испортила работу остальных. Forget разрешает новую загрузку, пока старая ещё работает: после него обещание «не больше одной функции в любой момент» неверно.

Ключ учитывает арендатора, права и параметры, влияющие на ответ. Общие карты и срезы требуют неизменности или копирования.

## Проверь себя

1. Является ли singleflight кэшем?
2. Почему отмену клиента отделяют от отмены загрузчика?

<details>
<summary>Ответы</summary>

1. Нет. Он объединяет одновременные вызовы, а не хранит завершённый результат для будущих.
2. Другие клиенты ещё могут ждать результат общей работы.
