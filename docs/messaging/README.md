# Сообщения и события

Сообщение позволяет одному сервису передать событие другому без одновременного выполнения. Например, заказ уже сохранён, а поиск обновит свой индекс позже. Между этими действиями возможны задержка, повтор и падение процесса.

[Kafka](kafka/README.md) хранит поток для независимых получателей. [Outbox: сохранение намерения отправить](transactional-outbox.md) связывает изменение базы с намерением отправить событие. [Inbox: защита эффекта от повторов](inbox-pattern.md) связывает отметку события с эффектом, защищая от повторной доставки.

Материалы ориентированы на Apache Kafka 4.3.1 и KRaft. Каждая гарантия имеет границу: подтверждение брокера ещё не означает успешную внешнюю операцию.
