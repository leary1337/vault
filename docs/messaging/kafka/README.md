# Apache Kafka

Исходная заметка 2024 года сохранена как [материал для аудита](legacy-overview.md), но не должна использоваться как актуальное руководство. Она будет заменена небольшими проверенными страницами об архитектуре KRaft, partitions, producer, consumer groups и delivery semantics.
