# Контейнеры

Контейнер упаковывает приложение и ограничивает его окружение. [Docker](docker/README.md) объясняет сборку и запуск, [Kubernetes](kubernetes/README.md) — управление множеством экземпляров, сетью и заменой версий. Это самостоятельные справочные темы, без обязательного порядка чтения.
