# Интервью

Этот раздел помогает объяснить знания на интервью. Технические механизмы находятся в основных статьях; здесь есть примеры рассуждения, чтения кода, проектирования и рассказа об опыте.

Уверенный ответ включает конкретный результат: что увидит программа, почему так произойдёт и какое изменение условий сломает вывод. Объяснение своими словами и новый пример полезнее заученной фразы.
