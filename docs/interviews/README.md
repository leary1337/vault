# Интервью

Подготовка должна тренировать объяснение mechanism, guarantees, failure modes и trade-offs, а не запоминание «правильных ответов». Основной учебник — тематические разделы Knowledge Base; здесь находятся карты навыков и mock formats.

## Маршруты

- language/runtime: [Go](../go/README.md);
- coding: [Algorithms](../algorithms/README.md);
- platform: [Linux](../linux/README.md), [networking](../networking/README.md), [databases](../databases/README.md), [production](../production/README.md);
- architecture: [System Design](../system-design/README.md), [distributed systems](../distributed-systems/README.md), [patterns](../backend-patterns/README.md);
- конкретная публичная карта этапов: [Avito](avito/README.md).

Формат найма меняется по компании, роли, уровню и моменту времени. Перед подготовкой запросите у рекрутера актуальные этапы, duration, допустимый язык/IDE, evaluation criteria и ожидания по system design.
