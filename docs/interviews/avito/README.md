# Интервью в Avito

На 6 октября 2026 проверен публичный [Avito playbook](https://github.com/avito-tech/playbook/blob/master/recruitment-and-office.md). В нём описаны программирование с написанием кода, практические и теоретические вопросы по платформе и дополнительное проектирование как важное отличие E5.

Здесь собраны способы объяснять решение и проверять свой ответ. Это публичная основа для подготовки, не закрытый список задач или гарантия этапов вашей вакансии. Материалы AvitoTech 2023 и 2025 сохранены с датами; у рекрутера уточняют текущие этапы, длительность, инструменты и требования.
