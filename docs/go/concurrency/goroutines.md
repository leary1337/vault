# Горутины

Горутина — выполнение функции, которым управляет Go. Планировщик может чередовать множество горутин поверх потоков ОС; отдельный поток каждой горутине не обещан.

```go
go serve(conn)
```

`go` не возвращает ручку ожидания, результат или ошибку. Это нужно организовать отдельно. Когда `main` возвращается, процесс завершается, не ожидая остальных горутин.

## Стоимость и владелец

Горутина начинает с небольшого растущего стека. Точные размеры меняются между реализациями. Она всё равно расходует память и удерживает ссылки, таймеры, дескрипторы и буферы. «Лёгкая» не означает бесплатная.

Для каждого запуска определите вход, завершение, отмену, получение ошибки и предел числа задач. Нужно знать, кто ждёт работу и освобождает её ресурсы.

```go
g, ctx := errgroup.WithContext(ctx)
g.Go(func() error { return consume(ctx, jobs) })
g.Go(func() error { return report(ctx) })
return g.Wait()
```

`errgroup` из `golang.org/x/sync/errgroup` не входит в стандартную библиотеку, но связывает ожидание, ошибку и отмену группы.

## Ожидание и отмена

```go
select {
case jobs <- job:
	return nil
case <-ctx.Done():
	return context.Cause(ctx)
}
```

Заблокированная горутина обычно не расходует CPU, но остаётся живой. Канал, сеть, таймер или блокировка должны иметь путь завершения. Паника в дочерней горутине не перехватывается родительским `recover`; допустимую границу восстановления устанавливают внутри запускаемой функции. `WaitGroup.Go` требует функции без паники.

## Полный запуск с ожиданием

```go
package main

import (
	"fmt"
	"sync"
)

func main() {
	var wg sync.WaitGroup
	wg.Go(func() { fmt.Println("finished") })
	wg.Wait()
}
```

В Go 1.25+ `finished` печатается до выхода `main`: `Wait` ждёт работника. Без него вывод не гарантирован. WaitGroup не отменяет зависшую функцию и не возвращает ошибку.

`errgroup.SetLimit(n)` ограничивает активные задачи, но сам вызов `Go` может ждать свободное место. Это не универсальная отменяемая очередь допуска: при отказе от лишней нагрузки нужна отдельная политика.

Не запускайте неограниченную горутину на каждый элемент и не отправляйте результат тому, кто уже ушёл по таймауту. `Sleep` не заменяет синхронизацию.
