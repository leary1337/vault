# Язык Go

Язык определяет, что происходит при присваивании, вызове функции и обработке ошибки. Для понимания важно различать копию значения и общие данные, статический тип и динамический тип интерфейса, обычную ошибку и panic. Примеры показывают конкретный результат, а не только определения.
