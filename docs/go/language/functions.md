# Функции

Функция объединяет действие, входные данные и результат. В Go параметры всегда передаются по значению: функция получает копию каждого аргумента.

## Определение и результаты

```go
func add(a int, b int) int {
	return a + b
}
```

`add` принимает два числа и возвращает их сумму. Общий тип соседних параметров можно написать один раз:

```go
func multiply(a, b int) int {
	return a * b
}
```

Результатов может быть несколько:

```go
func swap(x, y string) (string, string) {
	return y, x
}
```

У результатов могут быть имена. Они становятся переменными внутри функции, а `return` без списка возвращает их текущие значения:

```go
func split(sum int) (x, y int) {
	x = sum * 4 / 9
	y = sum - x
	return
}
```

В короткой функции это видно сразу; в длинной явный список результатов обычно проще читать.

## Передача параметров

```go
func modify(x int) {
	x = 10
}

func modifyPointer(x *int) {
	*x = 10
}
```

Вызов внутри `main`; нужен `fmt`:

```go
a := 5
modify(a)
fmt.Println(a) // 5, a не изменилось

modifyPointer(&a)
fmt.Println(a) // 10, a изменилось
```

`modify` меняет собственную копию числа, поэтому снаружи остаётся `5`. `modifyPointer` получает копию указателя, но этот указатель ведёт к исходному числу: запись через `*x` делает его равным `10`. Точно так же копии срезов и карт могут менять общие данные; договор о разрешённых изменениях нужен отдельно.

## Анонимные функции

```go
var add = func(x, y int) int {
	return x + y
}
fmt.Println(add(2, 3)) // 5
```

Функцию можно сохранить в переменной и передать как зависимость. Анонимная функция также может обращаться к внешним переменным; это [замыкание](closures.md). Функции нельзя сравнивать между собой, кроме проверки на `nil`.

## Variadic: сколько аргументов и какие данные общие

```go
func zeroFirst(xs ...int) {
	if len(xs) > 0 {
		xs[0] = 0
	}
}
```

Параметр `...int` внутри функции имеет тип `[]int`. Вызов со срезом и `...`:

```go
xs := []int{7, 8}
zeroFirst(xs...)
fmt.Println(xs) // [0 8]
```

Переданный срез продолжает ссылаться на исходный массив, поэтому результат — `[0 8]`. Присваивание самому параметру, например `xs = nil`, не заменило бы переменную вызывающего. Если изменение элементов запрещено, функция должна соблюдать этот контракт или работать с собственной копией.

2. Почему `zeroFirst(xs...)` меняет первый элемент исходного среза?
