# Замыкания

Замыкание — функция, которая сохраняет доступ к переменным окружающего блока. Это доступ к самой переменной, а не неизменная фотография её значения. Так функция может помнить состояние между вызовами.

## Счётчик с собственным состоянием

```go
func counter() func() int {
	count := 0
	return func() int {
		count++
		return count
	}
}
```

Использование:

```go
increment := counter()
fmt.Println(increment()) // 1
fmt.Println(increment()) // 2
fmt.Println(increment()) // 3
```

`count` остаётся доступен возвращённой функции после выхода из `counter`. Два вызова `counter()` создают независимые счётчики. Но копирование уже созданной функции сохраняет доступ к тому же счётчику.

## Изменение захваченной переменной

```go
func adder(base int) func(int) int {
	return func(i int) int {
		base += i
		return base
	}
}
```

Вызов:

```go
addFive := adder(5)
fmt.Println(addFive(2)) // 7
fmt.Println(addFive(3)) // 10
```

Замыкание увидит изменение внешней переменной, потому что читает её при вызове. Это удобно для обработчиков событий и передачи небольшой функции как зависимости. Если несколько горутин изменяют одну переменную, нужна синхронизация: замыкание не обеспечивает её автоматически.

## Захват переменной цикла

Для версии языка Go 1.22 и новее переменные, объявленные самим циклом через `:=`, создаются отдельно для каждой итерации:

```go
package main

import "fmt"

func main() {
	var callbacks []func() int
	for _, n := range []int{1, 2, 3} {
		callbacks = append(callbacks, func() int { return n })
	}
	for _, f := range callbacks {
		fmt.Println(f()) // go 1.22+: 1, 2, 3; go 1.21: 3, 3, 3
	}
}
```

Версию языка определяет строка `go` в модуле или ограничение сборки файла. Установка нового компилятора не меняет автоматически семантику старого пакета. Переменная, объявленная заранее и используемая через `for _, n = range ...`, остаётся общей во всех версиях.

Отдельная переменная итерации не делает независимыми данные под указателем или срезом. Поэтому Go 1.22 исправляет конкретную ловушку захвата, а не все гонки. Счётчик выше тоже рассчитан на последовательные вызовы.

## Сохранение окружения имеет цену

Долго живущая функция может удерживать большой захваченный объект. Например, обработчику нужен только идентификатор запроса, но захват всей структуры сохраняет также тело и буферы. Захватывайте необходимые данные. Компилятор может разместить окружение в куче; это зависит от срока жизни, а не является обязательной платой за любое замыкание.

## Проверь себя

1. Разделяют ли два вызова `counter()` одну переменную?
2. Почему отдельные переменные цикла не устраняют гонку на общей карте?

<details>
<summary>Ответы</summary>

1. Нет. Но две копии одной уже созданной функции разделяют её окружение.
2. Сами переменные разные, а карта, на которую они ссылаются, может оставаться общей.
