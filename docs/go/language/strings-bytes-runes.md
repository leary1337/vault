# Строки, байты и Unicode

Строка Go хранит байты. Один код Unicode в UTF-8 может занимать несколько байтов, а один видимый символ — несколько кодов. Поэтому прежде чем измерять или обрезать текст, нужно выбрать единицу.

## Что гарантировано

`string` неизменяема и может содержать любые байты, даже некорректный UTF-8. `len` считает байты, индексирование возвращает один байт:

```go
s := "Привет"
fmt.Println(len(s)) // 12 bytes in UTF-8
fmt.Printf("%x\n", s[0])

invalid := string([]byte{0xff, 0xfe})
fmt.Println(utf8.ValidString(invalid)) // false
```

`byte` — имя типа `uint8`; `rune` — имя `int32`, обычно используемое для кода Unicode. **Графема** — символ в восприятии пользователя, например буква с комбинируемым ударением. Она может состоять из нескольких `rune`.

## `range` по string

```go
for byteOffset, r := range "Go界" {
	fmt.Printf("%d: %U\n", byteOffset, r)
}
```

`range` декодирует UTF-8: индекс указывает байтовое смещение начала кода, а не его порядковый номер. При некорректной последовательности получается `utf8.RuneError` с продвижением на один байт. `utf8.RuneCountInString` считает декодированные коды, но не пользовательские графемы.

## Conversions и allocations

`[]byte(s)` даёт изменяемую копию байтов, `string(b)` — неизменяемое значение строки. Изменение исходного массива не должно менять полученную строку:

```go
payload := []byte("hello")
payload[0] = 'H'
text := string(payload)
```

Спецификация гарантирует результат, а не число выделений памяти: компилятор может убрать временное копирование, если наблюдаемое поведение сохраняется. Преобразования через `unsafe` без копии требуют строгого контроля срока жизни и запрета изменения общих байтов.

Для обработки текста есть `strings`, для изменяемых байтов и двоичных протоколов — `bytes`, для проверки и декодирования UTF-8 — `unicode/utf8`. Не переводите всю строку в `[]rune`, если достаточно пройти по ней: дополнительный массив тоже занимает память.

## Одинаково выглядит, по-разному хранится

```go
fmt.Println(len("é"), len("é")) // 2 3
fmt.Println("é" == "é")         // false
```

Во второй строке `e` и ударение записаны отдельно. Для поиска имён нужно выбрать правила нормализации Unicode и сравнения без учёта регистра. Простое приведение каждого кода к одной букве не описывает всех правил Unicode. В двоичном протоколе нормализация может вообще испортить данные.

## Ограничения внешнего текста

Сначала ограничьте число байтов до чтения или выделения большого буфера. Затем проверьте UTF-8, если следующий слой ожидает текст, и примените продуктовый лимит на коды или графемы. Срез строки по случайному байтовому индексу может разрезать код UTF-8. Управляющие символы внешнего ввода также нельзя без обработки вставлять в логи.
