# Измерения производительности в тестах

Benchmark измеряет стоимость операции, а не правильность. Сначала проверьте результат обычным тестом. Измерение хранится в `_test.go`, принимает `*testing.B` и с Go 1.24 может использовать `b.Loop`.

## Пример

```go
func BenchmarkJoin(b *testing.B) {
	words := []string{"go", "backend", "service"}
	for b.Loop() {
		_ = strings.Join(words, "/")
	}
}
```

Нужны `strings`, `testing`, Go 1.24+. `go test -run='^$' -bench=Join -benchmem` выводит время операции и выделения памяти. Подготовка до первого Loop не измеряется. Если создание данных и есть цель, перенесите его внутрь и объясните это.

Не смешивайте `b.N` и `b.Loop`. При разных размерах входа нужны отдельные измерения: три коротких слова не представляют мегабайтный ответ. Запускайте повторные выборки с `-count=N` и сравнивайте через benchstat.

Микроизмерение не заменяет итоговую нагрузочную проверку: оно не показывает очередь, сеть и p99 сервиса. Полный порядок работы — в [измерениях](../performance/benchmarks.md).
