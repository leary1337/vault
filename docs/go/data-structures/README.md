# Структуры данных Go

Встроенные коллекции имеют разные правила копирования. Struct копирует поля, slice остаётся окном в массив, map — общим словарём. Это влияет на изменения, память и безопасность доступа из goroutines; конкретная внутренняя реализация отделена от гарантий языка.
