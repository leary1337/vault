# Параметры типа

Обобщённая функция использует параметр типа вместо одного заранее выбранного типа. При вызове компилятор подставляет конкретный тип и проверяет разрешённые операции. В отличие от `any`, информация о типе результата не теряется.

```go
func Index[S ~[]E, E comparable](items S, target E) int {
	for i, item := range items {
		if item == target {
			return i
		}
	}
	return -1
}

type IDs []int64
```

Пример вызова:

```go
idx := Index(IDs{10, 20}, 20) // inferred: S=IDs, E=int64
```

`S ~[]E` допускает срезы с базовым типом `[]E`, включая именованный `IDs`. Компилятор выводит `S=IDs` и `E=int64`. Здесь результат поиска — `int`; сохранение имени среза важно у функций, возвращающих `S`, например `Clone[S ~[]E, E any](s S) S`. Возврат `[]E` уже не сохраняет имя `IDs`.

## Вывод типа

Обычно типы выводятся из аргументов. При присваивании самой обобщённой функции подходящая переменная тоже может дать контекст. Это не означает, что при вызове компилятор всегда выведет тип только из ожидаемого результата. При неоднозначности укажите часть или все параметры: `Index[IDs](...)`.

## Ограничения

Операция над `T` должна быть допустима для каждого типа ограничения. Проверка или переключение по конкретному типу работают с интерфейсом, а не непосредственно с параметром; при необходимости значение переводят в `any`. Нельзя полагаться на конкретное внутреннее представление и обещать отсутствие выделений памяти: стратегия генерации кода не является контрактом языка.

## Нулевое значение результата

```go
func First[T any](xs []T) (T, bool) {
	if len(xs) == 0 {
		var zero T
		return zero, false
	}
	return xs[0], true
}
```

`First([]int{})` вернёт `0,false`, а `First([]string{"go"})` — `"go",true`. Отдельный `bool` отличает отсутствие от настоящего сохранённого нуля.

`First(nil)` не даёт определить тип элементов. Нужен `First[int](nil)` либо переменная `var xs []int`.

Обобщения полезны, когда общий алгоритм должен сохранять конкретный тип данных. Если нужна только способность объекта выполнить несколько методов, обычный интерфейс может быть проще.

## Проверь себя

1. Почему `First(nil)` не позволяет вывести тип?
2. Зачем возвращать `bool` вместе с нулевым `T`?

<details>
<summary>Ответы</summary>

1. У нетипизированного `nil` нет типа элемента.
2. Нулевое значение может быть настоящим результатом; флаг отдельно обозначает его наличие.

</details>
