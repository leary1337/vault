# Ограничения и множества типов

Ограничение (**constraint**) перечисляет допустимые типы общего алгоритма и тем самым доступные операции. Компилятор должен разрешать операцию для всех типов этого множества.

```go
type Integer interface {
	~int | ~int8 | ~int16 | ~int32 | ~int64 |
		~uint | ~uint8 | ~uint16 | ~uint32 | ~uint64 | ~uintptr
}

func Sum[T Integer](values []T) T {
	var total T
	for _, value := range values {
		total += value
	}
	return total
}
```

`~int64` включает не только `int64`, но и определённые типы с таким базовым типом, например `type UserID int64`. Знак `|` объединяет множества. Части объединения, не являющиеся интерфейсами, не должны пересекаться.

## `any` и `comparable`

`any` — другое имя `interface{}`. Он допускает все типы, поэтому не разрешает специфические операции вроде сложения. `comparable` разрешает `==` и `!=` и нужен, например, ключам карты.

Интерфейсный тип может удовлетворять `comparable`, но сравнение его значений всё ещё может вызвать панику, если внутри одинаковый несравнимый конкретный тип. Обобщение не отменяет эту особенность интерфейсов.

## Обычные интерфейсы и ограничения типов

Обычный интерфейс, заданный методами, может быть типом переменной. Интерфейс с выражениями типов или объединениями обычно предназначен только для ограничения параметра или включения в другое ограничение:

```go
type Stringish interface {
	~string
}

// var x Stringish // invalid: interface contains type constraints
```

## Как ограничение влияет на вызов

После объявления `Sum` внутри `main`; нужен `fmt`:

```go
type UserID int64
fmt.Println(Sum([]UserID{10, 20})) // 30
// Sum([]float64{1.5}) // ошибка компиляции: float64 не входит в Integer
```

Без `~` часть `int64` включала бы только сам `int64`, а не `UserID`. Ограничение `~int | ~string` разрешает `+`, но это может быть сложение либо объединение строк. Общая синтаксическая операция ещё не означает общий прикладной смысл.

Начинайте с минимально нужных операций. Если достаточно метода, не перечисляйте конкретные типы. Используйте `~T`, только когда именованные типы с таким представлением действительно допустимы. Экспортируемое ограничение — часть API; его изменение затрагивает вызывающий код.
