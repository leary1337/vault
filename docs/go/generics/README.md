# Обобщённый код Go

Обобщённая функция или тип используют параметры типа, которые компилятор подставляет и проверяет. Ограничение задаёт допустимые типы и операции. Это позволяет сохранить конкретный результат, не писать один алгоритм много раз и не переводить всё в any.

Функции и типы доступны с Go 1.18, параметризованные псевдонимы — с 1.24, методы со своими параметрами — с 1.27. Методы интерфейса собственных параметров типа не имеют.
