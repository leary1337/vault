# Базы данных

База данных должна не только хранить данные, но и защищать правила их изменения. Два клиента могут одновременно редактировать цену, повторять запрос или потерять соединение в момент сохранения.

[Основы](fundamentals.md) объясняют выбор модели и ограничения. [PostgreSQL](postgresql/README.md) разбирает таблицы, транзакции и запросы. [Redis](redis/README.md) — быстрые операции в памяти, кэш и цену сохранности. Выбирайте статью по вопросу: что должен видеть читатель, что обязано сохраниться, где возникло ожидание.
