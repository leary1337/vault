# Application layer

Здесь рассматривается, как приложение находит сервер через DNS, получает настройки сети через DHCP и обменивается запросами через HTTP. TLS проверяет сервер и защищает канал. Важно понимать, какие гарантии заканчиваются на каждом промежуточном proxy.
