# Транспортные протоколы

TCP передаёт упорядоченный поток байтов, UDP — отдельные датаграммы без гарантии доставки, QUIC создаёт защищённое соединение с несколькими потоками поверх UDP. Выбор зависит от нужных гарантий; надёжная доставка сама по себе не доказывает выполнение операции.

Материалы: [TCP: надёжный поток байтов](tcp.md), [UDP: отдельные сообщения без гарантии доставки](udp.md) и [QUIC: несколько защищённых потоков поверх UDP](quic.md). Сравнивайте гарантии, устройство соединения, ожидание из-за потерь и поведение при отказах.
