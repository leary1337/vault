# Сетевой фундамент

IP выбирает адрес и путь к узлу, канальный уровень доставляет данные ближайшему соседу, а socket связывает обмен с процессом. Статьи объясняют эти границы на конкретном пути пакета, затем разбирают размер пакетов, адресацию и диагностические сообщения.
