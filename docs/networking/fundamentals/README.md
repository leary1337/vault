# Сетевой фундамент

IP задаёт адреса пакета, маршрутизация выбирает путь к узлу, канальный уровень доставляет данные ближайшему соседу, а сокет связывает обмен с процессом. Статьи объясняют эти границы на конкретном пути пакета, затем разбирают размер пакетов, адресацию и диагностические сообщения.
