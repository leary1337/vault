# Стандартизация сетей

### Описание
**Цель:** обеспечить возможность работать вместе оборудованию и ПО различных производителей.

**Типы стандартов:**
- *De jure (формальные, юридические)* - стандарты, принятые по формальным законам стандартизации. Пример: [ISO OSI](osi.md)
- *De facto (фактические)* - стандарты, установившиеся сами собой (новая технология, пользующаяся большой популярностью). Пример: [TCP/IP](tcp-ip-model.md)
