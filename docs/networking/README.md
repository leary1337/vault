# Сети

Рекомендуемый порядок: [фундамент](fundamentals/README.md) → [transport layer](transport/README.md) → [application layer](application/README.md).

После моделей OSI и TCP/IP переходите к IP addressing и sockets, затем к TCP/UDP/QUIC и HTTP/TLS/DNS. Production-связи — connection pools, keep-alive, TIME_WAIT и TLS handshake — будут добавлены отдельным проходом.
