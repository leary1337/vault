# База знаний Go backend

Это техническая база знаний и справочник по Go backend и смежным темам. Материалы можно читать в любом порядке: для поиска конкретной темы, повторения перед собеседованием или углубления в отдельный механизм.

Материалы раскрывают механизмы на примерах, затем разбирают ограничения и отказы, важные для Senior: конкуренцию, согласованность, нагрузку и эксплуатацию. В статьях есть схемы и вопросы для самопроверки с ответами. Незнакомую тему можно начать с вводного объяснения; к деталям возвращаться по конкретному вопросу.

Содержательная редакция выполнена 6 октября 2026 года. Дата статьи относится к её проверке, а версии и границы гарантий указаны в соответствующих разделах. База охватывает основные области Go backend интервью; конкретный набор вопросов зависит от вакансии и команды. Проверяйте понимание новым примером, а не количеством прочитанных страниц. Для ежедневного разговора с ассистентом используйте [устные занятия](voice-study.md).

В базе доступны материалы по [Go](go/README.md), [базам данных](databases/README.md), [Kafka](messaging/README.md), [сетям](networking/README.md), [распределённым системам](distributed-systems/README.md), [паттернам backend](backend-patterns/README.md), [проектированию систем](system-design/README.md), [Linux](linux/README.md), [контейнерам](containers/README.md), [наблюдаемости](observability/README.md), [архитектуре приложений](backend-architecture/README.md), [безопасности](security/README.md), [диагностике сбоев](production/README.md), [практике](practice/README.md) и [подготовке к интервью](interviews/README.md).
